Cài đặt AnkiVN

↕️ Sắp xếp thứ tự Fields (Kéo thả để thay đổi):

Đang tải...

🖱️ Field mặc định cho Context Menu:

Chọn field để thêm thông tin nguồn (URL, title). Chọn "Cùng field với text" để thêm vào field chứa text.

Ẩn Fields (Tích để ẩn):

Hãy chọn một Note Type ở trên.

📌 Ghim Fields (Giữ lại nội dung sau khi thêm):

Hãy chọn một Note Type ở trên.

🎲 ID ngẫu nhiên

Chọn field để tự động điền 14 số ngẫu nhiên khi thêm note mới (nếu field đó trống).

⚙️ Bật/Tắt Chức năng

Bật/tắt các chức năng trong popup. Các chức năng bị tắt sẽ không hiển thị trong giao diện.
